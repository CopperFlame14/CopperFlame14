### `01` — Smart Home Energy Forecasting & Waste Pattern Analysis

**Repository:** [`energypredictor_fds`](https://github.com/CopperFlame14/energypredictor_fds)

<div align="center">

![Python](https://img.shields.io/badge/Python-1a1b27?style=flat-square&logo=python&logoColor=7aa2f7)
![Scikit Learn](https://img.shields.io/badge/Scikit--Learn-1a1b27?style=flat-square&logo=scikitlearn&logoColor=e0af68)
![XGBoost](https://img.shields.io/badge/XGBoost-1a1b27?style=flat-square)
![Flask](https://img.shields.io/badge/Flask-1a1b27?style=flat-square&logo=flask&logoColor=c0caf5)

</div>

An end-to-end machine learning project focused on understanding household energy consumption, forecasting future demand, and identifying potentially inefficient usage patterns using a dataset containing approximately 100,000 observations.

**Inside the pipeline:**

- **Exploratory Data Analysis:** Investigates household energy usage, temporal behaviour, environmental variables and feature relationships.
- **Feature Engineering:** Prepares temporal and environmental variables for model training and prediction.
- **Model Benchmarking:** Compares Linear Regression, Decision Tree, Random Forest, K-Nearest Neighbors and XGBoost.
- **Dimensionality Reduction:** Applies Principal Component Analysis (PCA) to explore feature structure.
- **Consumption Pattern Analysis:** Uses K-Means clustering to group usage patterns and investigate potential energy-waste behaviour.
- **Time-Series Forecasting:** Uses ARIMA to generate a 30-day energy consumption forecast.
- **Prediction Interface:** Integrates trained models into a Flask application with prediction functionality and forecast visualizations.

**Core focus:** Predictive modelling, time-series analysis and pattern discovery in a practical energy-monitoring application.

### `04` — Two-Way Simple Chat Protocol (SCP)

**Repository:** [`simple_chat_v2`](https://github.com/CopperFlame14/simple_chat_v2)

<div align="center">

![JavaScript](https://img.shields.io/badge/JavaScript-1a1b27?style=flat-square&logo=javascript&logoColor=e0af68)
![Node.js](https://img.shields.io/badge/Node.js-1a1b27?style=flat-square&logo=nodedotjs&logoColor=9ece6a)
![Express](https://img.shields.io/badge/Express-1a1b27?style=flat-square&logo=express&logoColor=c0caf5)
![WebSockets](https://img.shields.io/badge/WebSockets-1a1b27?style=flat-square)

</div>

A computer-networks project exploring message exchange, protocol behaviour and bidirectional communication through an interactive protocol simulator and a live WebSocket implementation.

**Protocol exploration:**

- **Two-Way Communication:** Demonstrates communication initiated from both client and server sides.
- **Message Identification:** Uses message identifiers to associate messages with their corresponding acknowledgements.
- **Acknowledgement Handling:** Simulates ACK messages and tracks whether messages have been acknowledged.
- **Timeout & Retransmission:** Implements timeout handling and retry behaviour when acknowledgements are not received.
- **Packet Loss Simulation:** Simulates packet loss to observe how unreliable transmission affects communication.
- **Event Logging:** Displays message events, acknowledgements, timeouts and transmission failures.

**Live implementation:**

- Express server with WebSocket connections.
- Generates session codes for client connection.
- Supports a two-client session model.
- Relays messages between connected clients in both directions.
- Handles client disconnections and session resets.

**Core focus:** Communication protocols, acknowledgements, reliability, connection state and failure handling.

### `05` — House Price Prediction

**Repository:** [`HousePricePrediction_MRKrishni`](https://github.com/CopperFlame14/HousePricePrediction_MRKrishni)

<div align="center">

![Python](https://img.shields.io/badge/Python-1a1b27?style=flat-square&logo=python&logoColor=7aa2f7)
![Pandas](https://img.shields.io/badge/Pandas-1a1b27?style=flat-square&logo=pandas&logoColor=bb9af7)
![Scikit Learn](https://img.shields.io/badge/Scikit--Learn-1a1b27?style=flat-square&logo=scikitlearn&logoColor=e0af68)
![XGBoost](https://img.shields.io/badge/XGBoost-1a1b27?style=flat-square)

</div>

A supervised machine learning project exploring how housing attributes influence property prices and evaluating different regression algorithms on a housing dataset.

**Modelling workflow:**

- **Data Preparation:** Examines missing values, removes duplicate records and prepares features for modelling.
- **Categorical Encoding:** Converts categorical variables into machine-readable representations, including one-hot encoding.
- **Model Development:** Trains and compares Linear Regression, Random Forest Regressor and XGBoost Regressor.
- **Performance Evaluation:** Uses Mean Absolute Error (MAE), Root Mean Squared Error (RMSE) and the coefficient of determination (R²).
- **Comparative Analysis:** Evaluates model performance to understand the trade-offs between different regression approaches.

**Observed model results in the project analysis:**

| Model | R² Score |
|:---|---:|
| Linear Regression | 0.653 |
| XGBoost | 0.642 |
| Random Forest | 0.612 |

**Core focus:** Applying the complete regression workflow — from data cleaning and feature preparation to model comparison and evaluation.
